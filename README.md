# 빅데이터 중간고사 학습실

노션 수업 자료를 중심으로 정리한 한국어 강의와 표·그래프·코드 기반 종합 CBT입니다. 강의 → 데이터 읽기 → 종합 회차 → 채점 → 오답 → 연결 강의의 흐름을 구현했습니다. React + TypeScript + Vite로 만든 정적 웹앱이며 외부 인증 서버·DB 서버·AI API가 필요하지 않습니다.

**28개 강의 / 39개 서로 다른 사례 / 195개 직접 작성한 예상 연습문제 / 종합모의고사 1~5회차.** 각 회차는 A~H 전 범위의 고정 50문항·10개 자료입니다. 5회차 전체에서 195개 고유 문항을 모두 다루며 일부 사례는 회차 간 재등장합니다. 기본 75분은 조절 가능한 학습용 설정이며 실제 시험 규격은 미확정입니다.

2026-10-18 원자료 4개 172페이지를 재대조해 원자료 기반 설명 129개를 작성하고 각각의 PDF 페이지를 표시했습니다. 112개 추가 해설과 19개 정정, 39개 가상 사례·84개 자가 점검·6개 가상 입력 실습을 구분합니다. A~H의 8개 장은 장마다 한 페이지로 읽으며 왼쪽 메뉴 전체와 하위 메뉴를 접고 펼칠 수 있습니다. [페이지별 검토](docs/source-audit.md), [개편 안내와 검증](docs/lesson-upgrade.md)을 확인하세요.

## 실행

Node.js 22.12 이상(검증 환경 Node 24.18.0), npm을 사용합니다. 이 저장소의 폴더에서 실행하세요.

```sh
npm ci
npm run dev
```

[개발 서버](http://127.0.0.1:5173/BigData_CBT/)는 **127.0.0.1:5173**에 고정됩니다. 사용 중이면 오류로 종료하며 다른 포트로 바꾸지 않습니다. Windows에서 `npm ci`를 다시 실행할 때는 기존 Vite 서버를 먼저 종료하세요. 실행 중인 네이티브 바이너리 때문에 재설치가 잠길 수 있습니다.

```sh
npm run validate
npm test
npm run build
npm run preview
```

[Production 미리보기](http://127.0.0.1:4173/BigData_CBT/)는 **127.0.0.1:4173**입니다. 개발 주소·미리보기 주소·GitHub Pages는 **각각 다른 기록 저장소**입니다. `localhost`와 `127.0.0.1`도 다릅니다. 학습할 때 하나의 주소를 계속 사용하고 주소를 옮길 때는 백업으로 기록을 옮기세요.

## 학습과 계정

- 홈: 사용자, 이어서 읽기/풀기, 실제 진도·최근 점수·응시 수·복습할 오답.
- 강의실: A~H 상세 설명, 목표·용어 비교표·코드/줄별 해설·실수·확인 문제·사례·출처. 검색, 주제 필터, 목차, 읽기 완료, 북마크.
- 데이터 읽기: 39개 작은 표, 정렬/검색, 실제 결측 대체·삭제, 장르 펼치기, 건수/구성비, SVG 그래프·대체 표·확대·키보드 툴팁.
- CBT/모의고사: 종합 1~5회차, 회차당 50문항·10개 자료, 고정 문제 구성과 연속 사례 묶음. 같은 회차를 연습 또는 시험 모드로 풀며 번호 팔레트·검토 표시·선지 섞기를 지원합니다. 개별 자료·오답·북마크 복습은 별도 화면에 연결합니다.
- 연습: 답안 확인 뒤 해설. 시험: 제출 뒤 해설. 숫자는 표시한 단위·반올림·오차를 적용하고 숫자만 입력합니다. 짧은 답은 허용 용어로 판정합니다.
- 서술: 모범 답안과 채점 요소를 보고 자기 평가합니다. 작성한 서술은 자기 평가 전까지 점수를 보류하며 빈 답은 오답입니다. AI 자동 채점을 하지 않습니다.
- 기록/오답: 소유자별 응시·점수 추이·주제/기능/실수별 취약점·오답 횟수·해결/재풀이·북마크. 미응시 주제는 실력 0%로 표시하지 않습니다.
- 다크 기본/라이트, 사용자별 테마·선지 섞기 설정, 모바일 문제/공통 자료 전환, reduced-motion, 보이는 키보드 포커스.

게스트로 즉시 학습하거나 상단 프로필에서 **회원가입**을 선택해 아이디·표시 이름·비밀번호를 입력하세요. 아이디는 영문·숫자·`_`·`-` 3~32자, 비밀번호는 8~128자입니다. 가입/로그인 시 선택한 경우에만 게스트 기록을 현재 계정에 합칩니다. 게스트 원본은 보존하며 같은 ID를 재이전해도 항목이 중복되지 않습니다.

로그아웃은 탭의 세션을 바꾸며 저장 기록을 삭제하지 않습니다. 다시 로그인하거나 같은 주소에서 새로고침/서버 재시작하면 기록·선지 순서·답안·검토·종료 시각이 복원됩니다. 세션은 탭 단위이며 다른 탭의 로그인 사용자를 바꾸지 않습니다. 시간 만료는 절대 종료 시각을 기준으로 한 번 제출하며, 만료 후 늦은 답안 저장을 막습니다. 페이지를 닫아 둔 동안 만료되면 다음에 이어서 풀이를 열 때 자동 제출합니다.

## 백업과 저장 범위

프로필 → **내 기록 내보내기**로 현재 사용자만 JSON으로 백업합니다. 계정 목록·비밀번호·salt·검증값과 다른 사용자의 기록은 제외합니다. **백업 파일 선택**은 10MB 이하의 형식·버전·ID·참조·초안 선지 순서를 검사하며 적용 버튼을 누르기 전에는 기록을 바꾸지 않습니다.

**합치기**는 동일 응시 ID/오답 문제 ID/강의 ID/북마크 키에서 최신 항목을 유지합니다. 현재 초안이 있으면 우선합니다. 삭제한 항목은 과거 백업을 합치면 다시 나타날 수 있습니다. **덮어쓰기**는 현재 사용자의 학습 기록 전체를 교체하므로 먼저 백업하세요. 파일 내부 `userId`로 다른 계정을 수정하지 않으며 모든 소유자를 현재 계정으로 재지정합니다. 잘못된 백업은 기존 기록을 유지합니다.

출처(프로토콜·도메인·포트)가 바뀌면 로컬 기록 저장소도 달라집니다. 기존 GitHub 주소와 새 커스텀 도메인의 기록은 자동 이전되지 않으며, JSON 백업·복원으로 옮깁니다. HTTP와 HTTPS도 서로 다른 출처입니다.

계정·기록은 `bigdata-midterm-cbt:v1` IndexedDB, 탭 세션은 전용 sessionStorage 키를 사용합니다. [Web Crypto PBKDF2](https://developer.mozilla.org/en-US/docs/Web/API/SubtleCrypto/deriveBits) SHA-256·310,000회·사용자별 무작위 salt로 비밀번호 검증값을 만들고 원문을 저장하지 않습니다. 이 기능은 개인 로컬 프로필 분리이며 서버 인증이나 기록의 암호화 격리가 아닙니다. 같은 브라우저의 개발자 도구로 저장 데이터를 읽을 수 있습니다. 비밀번호 분실 시 계정 복구 서비스는 없습니다. 브라우저 저장소 삭제/비공개 모드/저장 용량 제한에 대비해 JSON을 별도로 보관하세요. 자동 기기 동기화는 없습니다.

## 자료와 정확성

시험 범위는 `2주차_노션.pdf`, `3주차_노션.pdf`, `4주차_넷플릭스_노션.pdf`, `빅데이터환경_개요.pdf` 4개 주자료입니다. 실제 개요 파일은 분해형 한글 이름이며 [출처 지도](docs/source-map.md)에 실제 이름을 기록했습니다. 웹사이트 PDF 3개는 같은 주제의 설명 보강에 사용했습니다. Titanic, 후반 로드맵, AI 제출 규칙, 보강만의 통계 범위는 제외했습니다. 넷플릭스 주자료의 네트워크·텍스트·추천·회귀는 포함했습니다.

모든 사례 수치는 **학습용 가상 데이터**입니다. 실제 Netflix의 시청 인기·투자·평점 결과를 재현했다고 주장하지 않습니다. 원본 CSV는 다운로드하지 않았습니다. 카탈로그 수≠시청 인기, 등급≠평점, 제작≠등록, 관계 수≠작품 수, Unknown≠실제 인물, 상관≠인과를 구분합니다. 원문의 MAE 불일치, 상수/소표본 평점 상관 오류 등은 [오류 검토](docs/content-issues.md)에 기록했습니다.

## 장별 한 페이지와 메뉴 접기

기존 A~H의 8개 주제는 각각 `/lessons/chapter/A`~`/lessons/chapter/H` 한 페이지로 읽습니다. 28개 단원의 원자료 기반 설명 129개·추가 해설 112개·정정 19개를 표시하며 39개 가상 사례 풀이, 195개 문제 및 회차 데이터를 유지합니다. 이전 `/lessons/A1`·`/lessons/H4` 및 `?topic=` 주소는 해당 장의 관련 위치로 연결합니다.

왼쪽 맨 위의 버튼으로 메뉴 전체를 접으면 본문이 넓어집니다. 상단의 펼치기 버튼으로 복원하며, 접힘 상태는 빅데이터 전용 설정으로 유지합니다. 모바일 메뉴는 Escape·배경 클릭·상단 닫기와 키보드 포커스 이동을 지원합니다. 장 전체 읽기 완료는 기존 단원 ID에 기록하므로 진도·북마크·과거 백업의 참조를 바꾸지 않습니다.

`npm run test:browser`는 별도로 `npm run preview`를 실행한 뒤 사용합니다. 320·390·768·1440px에서 8장 전체, 세부 메뉴, 기존 강의 주소, 코드·풀이 펼침과 진도·백업을 격리 브라우저로 검증합니다. Pages는 기존처럼 수동 배포하며 이 브라우저 검사를 통과한 빌드를 게시합니다.

## GitHub Pages 배포

Vite base는 GitHub 프로젝트 경로용 `/BigData_CBT/`, 라우터는 HashRouter입니다. 추후 커스텀 도메인 루트로 빌드하려면 환경 변수 `VITE_BASE_PATH=/`를 지정합니다. `#/lessons/H4` 같은 직접 접속/새로고침을 정적 호스팅에서 지원합니다. `.github/workflows/pages.yml`은 **workflow_dispatch만** 사용해 소스 push로 사이트를 게시하지 않습니다.

2026-10-12 후속 요청에 따라 GitHub Pages를 GitHub Actions 방식으로 활성화하고 **Publish Pages manually**를 실행해 공개 배포했습니다. [배포 실행](https://github.com/InsuHam0315/BigData_CBT/actions/runs/38265693195)의 콘텐츠 검사·테스트·빌드·배포가 성공했으며 HTTPS 실접속과 자산 5개의 로컬 빌드 일치를 확인했습니다. [공개 배포 검증](docs/deployment.md)에 결과를 기록했습니다.

이후 코드 변경을 배포하려면 Actions에서 `codex/bigdata-midterm-cbt` 브랜치를 선택해 **Publish Pages manually**를 수동 실행하세요. 원본 PDF·추출/렌더링·환경변수·인증정보·로컬 학습 백업·기존 프로젝트 자료를 저장소/배포 폴더에 포함하지 않습니다.

검증 화면은 가상 계정·가상 기록만 사용했습니다. 테스트 데이터와 비밀번호는 실사용 인증정보가 아닌 테스트 fixture이며, 브라우저의 계정 DB나 학습 JSON은 커밋하지 않습니다.
