# PDF 4개 종합 문제 · 개념 이해·적용 개정판

200문항을 전부 대조했다. PDF에 쓰인 숫자·문장·예시의 이름을 기억하는 대신, 개념을 상황에 적용하고 제시한 표·코드·그림을 해석하는 기준으로 점검했다.

## 점검 결과

| 판정 | 문항 수 | 처리 |
| --- | ---: | --- |
| 내용 개정 | 93 | 상황·조건·선지·해설을 다시 작성 |
| 표현 정리 | 11 | 이미 성립하는 개념 문제의 불필요한 자료 지칭을 제거 |
| 유지 | 96 | 필요한 조건이 있고 개념에 맞춰 상황을 분류·판단하는 문항 |
| 합계 | 200 | 개별 판정과 이전/새 ID는 `course-concept-review.json` |

단순한 표현 변경을 내용 개정에 포함하지 않았다. 200개 해설에서 반복하던 “원문 정의와 비교한다” 등의 일반 풀이 문구를 제거했다. 실제 원리·계산 과정과 선지별 오답 이유를 읽을 수 있다.

## 바꾼 문제의 예

| 기존 문제의 한계 | 개정 기준 |
| --- | --- |
| 전체 테스트 MAE 4.83년을 기억하는 문제 | 전체와 일부 샘플의 평균이 다른 이유 판단 |
| HDFS 128MB가 무엇의 예시인지 묻기 | 300 MiB 파일, 128 MiB 블록, 복제 3이라는 조건에서 3블록·9사본 계산 |
| 상자그림·산점도·이중 축의 이름만 고르기 | IQR 계산, x/y 좌표 해석, 다른 단위의 축 비교 |
| “교수님 도마 비유”의 표현 맞히기 | 실행 공간과 프로세스 간 메모리 보호 적용 |
| 상관 그림의 1.0과 원문이 맞는지 묻기 | 실제 제시한 평점표에서 공통 평가자 부족·상수 평점 판단 |
| 코드의 변수 이름만 고르기 | 날짜 파생값, explode 후 집계 단위, train/test 누수 판단 |

추가 수치 예시는 “학습용”이라고 표시했다. 원문 예측 샘플을 그대로 사용하는 경우도 모든 값을 문제에 제공한다. 원문 수치의 암기를 요구하지 않는다. 학습 범위는 제공된 4개 PDF의 개념에 한정한다.

## 자료·회차 구성

- 28문항에 표 또는 짧은 코드를 제공한다.
- 56문항에서 기존 PDF 원본 캡처를 연결한다. 차트·그림 25개는 모두 유지하며 그중 24개를 문항에서 사용한다. Netflix 차트 17개가 모두 포함된다.
- 각 회차는 환경·개요 10 / 빅데이터란 6 / 인프라 10 / Netflix 14문항이다.
- 5회×40문항이며 어느 회차도 단원 전용이 아니다.
- 회차당 실제 형광펜 개념 25문항(62.5%)과 일반 개념 15문항을 유지한다. 전체에서 22개 장과 형광펜 주석 44곳의 개념을 다룬다.
- 정답 위치는 1~4번 각각 10문항이며 섞은 뒤에도 균형과 저장 순서를 유지한다.
- 중하 32·중 6·상 2는 출제 목표이며 실측 난이도는 아니다.

## 이전 학습 기록

새 문항 ID는 `C26V2R01Q01` 형식이다. 회차 URL은 `course-1`~`course-5`를 유지한다. 개정 전 `C26R...` 200문항은 `src/content/course/archive-questions.json`에 원래 내용·선지 ID·정답 그대로 보존했다.

새 회차와 새 장별 연습에서는 개정판을 사용한다. 저장된 이전 풀이·응시·오답·북마크·백업은 당시 문제를 참조한다. 예전 풀이에 들어가면 개정 전 문항이라는 안내와 새 회차 링크가 표시된다. 사용자 기록을 새 정답으로 재해석하지 않는다.

## 검증

- `npm run validate`: 범위·참조·그림 해시·형광펜·문항 수·정답 배치·문항 형식 검사 통과.
- `npm test`: 43개 통과. 블록/사본 수, 중복 결측 삭제, IQR, MAE, 장르별 분모, 평점의 공통 관측/변동성 등을 독립 계산했다.
- 이전 200문항의 의미적 SHA-256 고정 검사와 새 연습 제외 검사 통과.
- 이전 응시 중 상태의 선택 순서·정답·오답·북마크 백업 복원 검사 통과.
- `npm run build`: TypeScript와 배포 빌드 통과.
- 로컬 앱 브라우저: 개정판 진입, 제시 표, 오답/정답 색, 해설, 재접속 복원, 모바일 가로 넘침, 원본 차트 확대 확인.
- GitHub Pages 배포 워크플로: 기존 6개 브라우저 검사와 개정 200문항의 표/코드 표시·채점·결과/기록·이전 문항 복습 검사를 실행한다. 실제 실행 결과는 해당 커밋의 Actions에서 확인한다.

원본 PDF·인증 정보·개인 학습 기록을 새로 추가하지 않았다. 모든 테스트 데이터는 독립된 테스트 프로필의 가상 응답이다.

## 재생성

`scripts/course_questions/concept_revision.py`가 문서·개념·회차별 변경을 정의한다. `python scripts/build_course_exam.py`로 문항·회차·점검표를 함께 생성한다. 기존 저작 모듈은 개정 전 비교 기준으로 남아 있으므로 최종 출제본은 반드시 생성된 `src/content/course/questions.json`을 사용한다.
