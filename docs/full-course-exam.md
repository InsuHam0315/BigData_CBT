# PDF 4개 전체 종합 모의고사와 원본 차트 · 2026-10-21

현재 모의고사의 기준은 개요 63쪽, 빅데이터란 15쪽, 인프라 25쪽, Netflix 66쪽의 **제공된 필기본 4개 전체**입니다. 회차 ID는 `course-1`~`course-5`, 개념 적용 개정판 문항은 `C26V2R01Q01` 형식입니다. CBT는 빅데이터1-3장.pdf의 별도 200문항을 사용합니다. 개정 전 `C26R...`와 이전 19쪽 문제도 기록용으로 보존합니다. [메뉴·링크 분리 기준](assessment-split.md). [전체 점검·개정 내역](course-concept-revision.md).

## 회차 구성

| 항목 | 각 회차 |
| --- | ---: |
| 전체 | 40문항, 4지선다 |
| 환경·개요 / 빅데이터란 / 인프라 / Netflix | 10 / 6 / 10 / 14 |
| 교수님 형광펜 개념 / 일반 내용 | 25 / 15 |
| 난이도 중하 / 중 / 상 | 32 / 6 / 2 |
| 정답 표시 위치 1 / 2 / 3 / 4번 | 10 / 10 / 10 / 10 |
| 시험 기본 시간 | 60분, 1~240분 조절 |

5회차 200문항은 서로 다른 질문·ID를 갖습니다. 주요 개념은 회차마다 다른 상황·관점으로 반복 복습합니다. 전체 세트는 22개 장과 실제 Highlight 주석 44곳의 개념을 다룹니다. 어느 회차도 한 단원 전용이 아니며, 같은 PDF의 문제가 네 개 연속되지 않도록 혼합합니다. 62.5%라는 비중은 원문 강조 개념의 배분이며 실제 출제 가능성이나 점수를 보증하지 않습니다. 난이도도 실측 정답률이 아닌 출제 목표입니다.

원문 페이지·형광펜 ID·장·그림 ID를 각 문항에 기록합니다. [구조 검증 보고서](course-exam-audit.json)는 회차별 분포, 22장/44주석의 포함 여부, 그림 사용, 정답 배치와 선지 길이 지표를 제공합니다. 길이 검사는 보조 지표이며 문항의 모든 단서를 배제했다는 증명은 아닙니다.

## 실제 원본 그림

`public/figures/`의 PNG 25개는 PDF를 MuPDF 2.5배로 렌더링한 실제 캡처입니다. 넷플릭스의 차트 17개는 이미지 영역과 축·범례를 포함해 캡처했고, 환경·운영체제 그림 8개는 형광펜을 보존한 전체 슬라이드입니다. 합계 약 5 MB이며 페이지의 이미지는 필요할 때 로딩합니다. 새로운 그래프로 다시 그리거나 값을 바꾸지 않았습니다.

- 막대·파이·히스토그램, 상자그림·산점도·히트맵, 시간 추이·이중 축, 네트워크·워드클라우드·아이템 유사도 표를 포함합니다.
- `/figures`에서 모든 원본을 찾고 축·범례·읽는 순서·해석 문장·주의점을 확인합니다. 필기노트에도 해당 개념 옆에 실제 그림을 넣었습니다.
- `크게 보기`는 네이티브 대화상자에서 확대합니다. 작은 화면에서는 그림 안을 가로·세로로 이동해 작은 라벨을 읽습니다. Escape 또는 닫기로 돌아옵니다.
- 시험 중에는 원본 그림과 필요한 조건만 보입니다. 읽는 법·주의·풀이 내용은 문항 확인 또는 전체 제출 이후에 제공합니다. 연습과 시험의 공개 시점은 구분합니다.
- PNG의 문서·페이지·캡처 좌표·크기·파일 및 픽셀 SHA-256은 `src/content/source-figures.json`에 있습니다. `python scripts/capture_source_figures.py --verify`는 원본 PDF에서 다시 렌더링해 대조합니다.

## 원문 검증에서 주의한 점

국가×장르와 장르×등급 그림은 각각 실제 PDF p39와 p37입니다. 축·셀·제목을 직접 대조했습니다. 산점도는 공개 연도 x·등록 연도 y이므로 구작의 늦은 등록은 y>x입니다. 원문 위치 설명과 구분합니다. 가상 투자액, 부분 연도, 첫 국가·첫 장르 선택, 복수 장르 관계의 분모도 명시했습니다.

아이템 유사도 그림은 원본을 보존합니다. 단, 원문 작은 평점에서 The Matrix는 공통 평가자에게 모두 5점이고 Inception의 평가는 한 명뿐이므로 해당 상관에 NaN이 생길 수 있습니다. 원문 p57의 1.0 설명이나 그림의 관련 숫자를 재현된 추천 성능으로 확정하지 않습니다. MAE는 p64의 4.19년과 p65의 4.83년, 네 샘플의 1.75년을 서로 다른 표기·표본으로 구분합니다.

## 기록 보존과 검증

DB와 백업 스키마는 유지합니다. 예전 `F01Q01` 등과 새 문항은 같은 ID를 재사용하지 않습니다. 예전 기록을 새 정답으로 재채점하거나 이름을 바꾸지 않습니다. 새 PDF 진도는 `PN1`~`PN4`이며 기존 A~H·FN1~FN3 진도와 함께 보관·백업됩니다. 기존 로컬 서버의 풀이도 덮어쓰지 않고 별도 검증 원점과 자동 검사의 격리된 프로필을 사용합니다.

검증 명령:

```sh
python scripts/build_course_exam.py
python scripts/capture_source_figures.py --verify
npm run validate
npm test
npm run build
# preview가 실행된 상태에서 자동 검증:
npm run test:browser
npm run test:final-browser
npm run test:handout-browser
npm run test:notebook-browser
npm run test:course-browser
```

단위 테스트 46개에는 선지 섞기 후 채점, MAE·블록·분모 등 독립 계산, 새 응시·오답·북마크·진도와 기존 자료가 함께 있는 백업 복원이 포함됩니다. 브라우저 검사는 320·390·768·1440px에서 모든 그림과 확대·노트 연결을 검사하고, 휴대폰·데스크톱에서 5회차 응시·재접속·제출·점수·기록을 확인합니다. 개정판 200문항의 표·코드 렌더링과 개정 전 기록용 문항 복습도 검사합니다. 19쪽 200문항 검사도 유지합니다.
