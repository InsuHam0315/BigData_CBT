# PDF 전체 필기용 핵심노트 · 2026-10-21

요청한 네 필기본은 기존 `/handouts` 자료실에 원본으로 있었고, 관련 개념은 이전 강의에도 있었습니다. 기존 첫 화면의 1~3장 긴 설명은 별도의 19쪽 최종 범위 자료를 따릅니다. 이번 변경은 그 설명을 유지하면서, **네 PDF 전체 범위를 간결하게 옮겨 적는 별도 페이지**를 추가합니다.

## 읽는 방법

- [전체 필기 입구](https://insuham0315.github.io/BigData_CBT/#/notebook)에서 PDF를 선택합니다.
- 용어는 `단어: 핵심 설명`으로, 세부는 짧은 불릿으로 정리합니다. 비교는 표, 순서는 흐름도로 표현합니다.
- 각 장 끝의 Summary는 다시 적고 복습할 핵심 문장입니다. [22개 장 Summary 모아보기](https://insuham0315.github.io/BigData_CBT/#/notebook?view=summary)도 제공합니다.
- 노란 강조와 `★ 교수님 강조`는 실제 PDF Highlight 주석 44곳을 대조한 결과입니다. 다른 내용도 기본 화면에서 모두 읽습니다. 일반 메모·손그림을 임의로 교수님 형광펜으로 분류하지 않습니다.
- `교수님 강조만`과 내용 검색을 함께 사용할 수 있습니다. 5V 표에서는 실제 칠해진 3V만 강조하고 신뢰성·가치는 일반 행으로 유지합니다.
- `필기 복사`는 현재 화면에 표시되는 검색·강조 조건의 내용만 복사합니다. `인쇄`는 메뉴·검색·버튼을 제외한 노트를 인쇄합니다.
- 각 내용의 `원본 p…` 링크는 해당 PDF의 실제 쪽으로 연결합니다. 표지·반복 목차·연락처·빈 쪽은 학습 문장으로 복제하지 않았습니다.

## 원문과 구별해 적은 내용

- Linux/FreeBSD 계열, 가상 주소 공간의 단순화, FAT32 볼륨과 단일 파일 한계는 `바로잡기`로 표시하고 공식 근거를 연결합니다.
- HDFS 블록·복제 수는 설정 가능한 값이며, 공유 편집 로그와 ZooKeeper의 역할을 구별합니다.
- 넷플릭스 7,787행과 전처리 화면의 7,770행을 구분하고, 별도 최종 범위의 고정본 수치와 혼용하지 않습니다.
- 공개 연도 x·등록 연도 y 산점도의 구작 위치는 좌표로 바로잡습니다. 카탈로그 보유량을 시청 인기·국가 선호로 단정하지 않습니다.
- 자료의 투자액은 가상 데이터입니다. 첫 국가·첫 장르 선택, 상위 항목 필터, 부분 연도 등 집계 조건을 명시합니다.
- 아이템 협업 예제의 공통 평가자 부족·상수 평점으로 생기는 NaN을 높은 유사도로 해석하지 않습니다.
- MAE는 p64의 4.19년과 p65의 4.83년을 그대로 구별합니다. p65 표 기준 감소는 6.22→4.83, 1.39년·약 22.3%이며, 제시한 네 샘플의 평균 절대 오차 1.75년은 전체 테스트 결과와 다른 표본입니다.

## 근거와 재생성

편집 원본은 `scripts/notebook_content/*.py`와 `scripts/build_notebook.py`이며, `python scripts/build_notebook.py`로 `src/content/notebook.json`을 재생성합니다. 원문 추출을 그대로 화면에 출력하는 방식이 아니라 직접 작성한 설명·표·흐름을 생성합니다.

- [내용 구조 검사](notebook-content-audit.json): 자료·장·단원·블록·Summary 개수와 참조 범위.
- [PDF 대조 검사](notebook-source-audit.json): 원본 SHA-256, 실제 주석 ID·색, 169쪽 전체의 단원/제외 사유 장부. `python scripts/verify_notebook.py`로 재검사합니다.
- 검토 시 169쪽을 읽고, 그림인 컴퓨터 발전·배포판 표와 필기 주석이 있는 33쪽을 렌더링해 대조했습니다. 쪽수 장부는 추적 가능성을 검사하며 의미상 누락 여부의 수동 검토를 대신하지 않습니다.
- 원본 4개는 기존에 공개된 파일을 그대로 사용합니다. 새 PDF·원문 추출·검토용 이미지·인증 정보·개인 학습 기록은 추가하지 않습니다.
