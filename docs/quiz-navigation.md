# 문제풀이 피드백·이동 개선 · 2026-10-21

- CBT와 모의고사에서 **답안 확인 이후** 선택한 오답은 빨간 배경·테두리·글씨와 `× 내 오답`으로, 정답 선지는 초록색과 `✓ 정답`으로 표시합니다. 색을 구분하기 어려운 경우에도 문구로 결과를 알 수 있습니다.
- 문제 번호에 확인한 정답·오답을 표시하고, 해설의 내 답과 제출 결과·오답노트에도 오답을 빨간색으로 표시합니다. CBT와 모의고사 모두 문항별 답안 확인을 누르면 정답·오답과 해설을 보여 줍니다. 누르기 전에는 정답을 표시하지 않습니다.
- 답을 수정하면 이전 판정을 지우고 다시 답안을 확인하게 합니다. 서술형은 자기 평가 전에는 정답·오답을 확정하지 않습니다. 기존 채점·저장·문항 ID는 유지합니다.
- 이전·다음과 현재 번호는 문제 위의 고정 도구 모음에 있습니다. 긴 해설을 내려 읽어도 이동할 수 있습니다.
- 1200px 이상에서는 문제 번호를 오른쪽에 고정합니다. 그보다 작은 화면에서는 상단의 `번호` 버튼으로 엽니다. 번호 선택 후 목록을 접고 해당 문제로 이동하며, Escape로 닫을 수 있습니다.

`npm run test:quiz-navigation`은 임시 프로필에서 1~3장 CBT와 필기본 4개 모의고사를 각각 320·390·768·1199·1440px로 검사합니다. 오답·정답 색상, 다크/라이트 테마, 답 수정 후 판정 초기화, 재접속, 상단 이동과 번호 선택, 전체 제출 결과를 확인합니다. 모의고사도 답안 확인 버튼의 표시·미응답 시 비활성화·개별 해설·다음 문제의 정답 비공개·재접속 복원·답 수정·전체 제출을 검사합니다. 두 자료의 400문항 브라우저 검사도 유지합니다.

출제 자료를 분리하면서 모의고사가 시험 모드로만 연결되어 문항별 확인 버튼이 숨겨졌던 조건을 제거했습니다. 이미 저장된 시험 모드 풀이에도 즉시 적용되며 새로 시작할 필요가 없습니다. 저장 스키마·문제은행·제한 시간·전체 제출 동작은 유지합니다. 개별 확인은 풀이 상태에 저장하고, 응시 점수와 오답노트는 전체 제출 시 기록합니다.
