# 문제풀이 피드백·이동 개선 · 2026-10-21

- 연습에서 **답안 확인 이후** 선택한 오답은 빨간 배경·테두리·글씨와 `× 내 오답`으로, 정답 선지는 초록색과 `✓ 정답`으로 표시합니다. 색을 구분하기 어려운 경우에도 문구로 결과를 알 수 있습니다.
- 문제 번호에 확인한 정답·오답을 표시하고, 해설의 내 답과 제출 결과·오답노트에도 오답을 빨간색으로 표시합니다. 모의고사는 제출 전 정답 여부를 보여 주지 않습니다.
- 답을 수정하면 이전 판정을 지우고 다시 답안을 확인하게 합니다. 서술형은 자기 평가 전에는 정답·오답을 확정하지 않습니다. 기존 채점·저장·문항 ID는 유지합니다.
- 이전·다음과 현재 번호는 문제 위의 고정 도구 모음에 있습니다. 긴 해설을 내려 읽어도 이동할 수 있습니다.
- 1200px 이상에서는 문제 번호를 오른쪽에 고정합니다. 그보다 작은 화면에서는 상단의 `번호` 버튼으로 엽니다. 번호 선택 후 목록을 접고 해당 문제로 이동하며, Escape로 닫을 수 있습니다.

`npm run test:quiz-navigation`은 임시 프로필에서 새 종합 회차와 이전 19쪽 회차를 각각 320·390·768·1199·1440px로 검사합니다. 오답·정답 색상, 다크/라이트 테마, 답 수정 후 판정 초기화, 재접속, 상단 이동과 번호 선택, 제출 결과, 시험 중 정답 비공개가 대상입니다. 기존 종합·이전 회차 400문항의 브라우저 검사도 유지합니다.
