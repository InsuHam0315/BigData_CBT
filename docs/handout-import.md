# 수업 필기본 추가 · 2026-10-19

사용자가 사이트 추가를 요청한 아래 4개 PDF를 `public/materials/`에 원본 그대로 복사했다. 기존의 원본 PDF 제외 규칙에는 이 네 파일만 예외로 등록했다. 다른 원자료·추출문·검토 이미지·개인 기록은 공개하지 않는다.

총 169쪽이다. 페이지 번호는 각 필기본 PDF의 실제 순서이며 이전 비필기본의 쪽수를 재사용하지 않았다. 인프라와 Netflix 필기본은 이전 자료와 전체 쪽 수도 다르다.

PDF 본문·주석·형광펜·손글씨·텍스트 메모를 수정·평면화하지 않았다. 파일 크기와 SHA-256은 `src/content/handouts.json`에 기록한다. `scripts/import_handouts.py <원본 폴더>`는 원본을 읽어 복사하고 주석 페이지·목차·관련 노트 목록을 생성하며 원본과 바이트가 일치하는지 확인한다. 문서에 포함된 코드·링크·명령은 실행하지 않는다.

표지와 필기 표시가 있는 33쪽을 주석이 보이는 상태로 렌더링해 확인했다. 목차는 각 파일의 제목·단원 시작 쪽을 직접 대조했다. 이 작업은 원본 자료실 추가이며 PDF의 모든 서술을 새로운 사실로 검증하거나 최종 시험 범위로 확장하는 작업은 아니다.

`/handouts`에서 목록, `/handouts/:documentId?page=N`에서 자료·목차·주석 쪽·미리보기·새 탭 보기·다운로드를 제공한다. 파일 링크는 Vite의 설정된 기본 경로를 사용하므로 GitHub Pages의 `/BigData_CBT/` 아래에서도 동작한다. 다운로드 시 원래 한글 파일명을 사용한다. 미리보기는 선택했을 때 한 파일만 불러오며 브라우저 PDF 뷰어를 사용한다. 해당 뷰어를 지원하지 않는 환경에서도 새 탭·다운로드 링크를 사용할 수 있다.

첫 화면·왼쪽 메뉴·최종 범위 노트에 자료실 링크를 추가했다. 19쪽 최종 범위 PDF, 200문항·5회차의 난이도/정답 위치, 저장소·백업 형식은 그대로 유지한다.

검증은 4개 화면 폭에서 목록·쪽 이동·주석 링크·관련 노트·다운로드와 원본 SHA-256 일치를 확인한다. 기존 메뉴·백업 검사, 콘텐츠 검증·27개 단위 테스트, 배포 과정의 기존 5회차 풀이 검사도 유지한다. 배포 후 공개된 PDF의 파일 크기·해시와 HTTPS 접근을 다시 확인한다.
