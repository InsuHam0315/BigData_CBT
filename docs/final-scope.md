## 모의고사와 문항 검토

회차당 40문항, 5회차 총 200문항이다. 서로 다른 ID와 질문을 사용하며 범위의 핵심 개념은 반복 복습한다. 모두 직접 작성한 4지선다 예상문제로 교수님이 작성한 실제 시험 문제가 아니다. 매 회차 1장 9·2장 13·3장 18문항이며, 페이지 분량과 적용 주제를 고려한 사이트의 구성이다. 교수님이 장별 배점을 확정했다고 주장하지 않는다.

난이도는 매 회차 상 2(5%)·중 6(15%)·중하 32(80%)다. 중하는 정의/기본 구별, 중은 수치/코드/상황 적용, 상은 복수 조건의 오류 진단과 해석으로 작성했다. 실제 정답률을 측정한 난이도가 아니다.

정답은 1~4번 각 10개다. 고정 순서뿐 아니라 선지 섞기에서도 정답 위치를 균형 있게 배치한 뒤 오답만 섞고, 그 순서를 초안에 저장한다. 학습 중 재접속해도 선택과 채점 기준이 달라지지 않는다. 문항 순서에는 고정된 혼합 순서를 적용하여 난이도·장 순서로만 나열하지 않는다.

선지는 문장 길이와 설명의 구체성을 맞추고, 정답에만 근거를 덧붙이지 않았다. 오답은 단위·관찰 대상·분모·단계·검증 근거의 혼동을 중심으로 검토했으며 문항 주제와 무관한 선택지를 줄였다. 정답이 유일한 최장 선지인 문항은 회차별 3·5·3·4·7개다. 평균 정답/오답 글자 수와 쪽수별 연결은 `final-scope-audit.json`에 기록한다. 길이 검사는 편집 보조이며 모든 문항의 측정 타당성을 자동 보증하지 않는다.
