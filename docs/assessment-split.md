# 출제 자료별 CBT·모의고사 분리 · 2026-10-21

기존에는 CBT와 모의고사가 모두 `course-1`~`course-5`를 불러왔다. 이제 CBT는 빅데이터1-3장.pdf, 모의고사는 필기본 PDF 4개 전체를 사용한다.

| 구분 | CBT | 모의고사 |
| --- | --- | --- |
| 자료 | 빅데이터1-3장.pdf, 19쪽 | 환경·개요 / 빅데이터란 / 인프라 / Netflix 필기본, 169쪽 |
| 주소 | `#/cbt` | `#/mock` |
| 회차 ID | `final-1`~`final-5` | `course-1`~`course-5` |
| 문항 ID | `F26R...` | `C26V2R...` |
| 구성 | 5회 × 40문항 | 5회 × 40문항 |
| 모드 | 연습, 시간 제한 없음 | 시험, 기본 60분 |
| 해설 공개 | 문항별 답안 확인 | 전체 제출 뒤 |
| 강조 개념 | 1~3장 범위의 기존 개념 적용판 | 교수님 강조 매회 25문항(62.5%) |

새 문항을 복제하거나 기존 문제 내용을 바꾸지 않고 이미 검토한 두 문제은행을 각각 연결했다. 단원별 회차로 나누지 않았고, 개념 적용·표·코드·차트 해석 기준도 유지한다. 사이드바의 중복 ‘개념 종합’ 메뉴를 통합하고 출제 자료를 메뉴·목록·응시 설정에 명시했다. 홈·필기노트·자료실·안내 페이지도 같은 구분을 사용한다.

## 기존 기록과 링크

- DB·백업 스키마, 문제 ID·정답, 진행 중 풀이·선지 순서·응시·오답·북마크·진도는 수정하지 않는다.
- 이전 `#/cbt/course-N`은 `#/mock/course-N`, `#/mock/final-N`은 `#/cbt/final-N`으로 이동한다. 자료가 바뀌지 않도록 회차의 출처를 우선한다.
- 이전 두 `?scope=concept` 목록 링크는 `#/cbt`로 이동한다.
- 195문항 보관함의 `mock-N` 경로는 이전 문제와 모드를 유지한다.
- 예전에 저장한 4개 PDF 연습 또는 19쪽 시험은 원래 모드로 이어 풀 수 있다. 새 회차를 시작할 때만 현재 메뉴의 구분을 적용한다.
- 결과의 ‘같은 회차 다시 풀기’와 개정판 이동 링크도 출제 자료를 따라간다. 바뀐 응시 제목에 의존하지 않도록 현재 문제 ID 집합으로 회차를 찾는다.

## 검증

- `npm run validate`: 기존 범위·문항·차트·정답 검증 통과.
- `npm test`: 46개 통과. 두 은행 각 200개, ID 교집합 없음, 출처와 연습/시험 모드, 이전 경로·기록의 출처 판별을 포함한다.
- `npm run build`: TypeScript와 배포 빌드 통과. 기존 대형 번들 경고는 남아 있다.
- 로컬 앱 브라우저는 별도 테스트 원점에서 두 목록·회차·실제 문항 ID·모드를 확인한다. 공개 사이트의 개인 풀이를 새로 시작하거나 덮어쓰지 않는다.
- 배포 전 GitHub Actions에서 6개 브라우저 검사를 실행한다. CBT와 모의고사의 10개 회차, 실제 400문항의 채점·저장·결과, 올바른 재응시 링크, 구주소 이동, 모바일·데스크톱 메뉴, 오답 색상·상단 이동·시험 중 해설 비공개를 검사한다. 해당 커밋의 Actions 성공 여부가 최종 실행 결과다.

원본 PDF·개인 기록·인증 정보는 이번 변경에 추가하지 않았다.
